### 🚀 终极懒人包（Windows 用户专用）



将下面的代码保存为 **`avif2gif.bat`** 文件，放在桌面。以后直接把 `.avif` 文件拖到这个批处理图标上，就会自动生成同名的 `.gif` 文件。

```batch
@echo off
if "%~1"=="" (
    echo 请将 .avif 文件拖拽到此脚本上
    pause
    exit /b
)
ffmpeg -i "%~1" -filter_complex "[0:v:1]fps=20,split[a][b];[a]palettegen=stats_mode=diff[p];[b][p]paletteuse" "%~n1.gif"
pause
```

---

### 📝 新手必看：完整转换命令（带调色板优化）

如果你习惯在命令行手动输入，直接复制这一整行即可（记得把文件名改成你的）：

```bash
ffmpeg -i 沃爱你们.avif -filter_complex "[0:v:1]fps=20,split[a][b];[a]palettegen=stats_mode=diff[p];[b][p]paletteuse" 输出.gif
```

#### 这条命令的潜台词（给新人的解释）：

1. **`[0:v:1]`**：强行指定使用第 **2** 个视频流（动图流）。如果不指定，FFmpeg 默认取第 1 个流，你只会得到静态首帧。
2. **`fps=20`**：将帧率降到 20。因为原文件可能是 60fps，直接转出来的 GIF 会**体积爆炸**且**播放飞快**，20~25 帧是比较舒服的速度。
3. **`palettegen/use`**：生成优化的 256 色调色板。这是**画质灵魂**，不加这个直接转，颜色会严重失真（发灰、噪点多）。

---

### ⚡ 应急备用：极简命令（不讲究画质时用）

如果你不 Care 画质，只想看一眼效果，用这个最简单的：

```bash
ffmpeg -i 沃爱你们.avif -map 0:1 -vf "fps=20" 输出.gif
```

> 去掉调色板步骤，速度飞快，但颜色会变差。

---

### 🧐 给新人的三个“避坑”提醒

1. **关于选流**：AVIF 格式比较特殊，内部常包含“静态缩略图（Color）”和“动态画面”两个轨道。**不指定 `[0:v:1]` 或 `-map 0:1`，永远只能得到静态图。**（这是 90% 新人失败的原因）

2. **关于帧率**：源文件通常是 60 帧/秒，GIF 不适合这么高的帧率。建议设为 **15~25**，文件会小很多，观感也正常。

3. **关于画质**：GIF 只支持 256 色，而 AVIF 是广色域。直接转换就像把水彩画压成蜡笔涂鸦。只有加上 `palettegen` 调色板步骤，才能让颜色过渡相对平滑。

### 💡 调整参数小贴士

- 如果想调速度/大小：把命令里的 `fps=20` 改成 `fps=15`（更慢更小）或 `fps=30`（更快更大）。
- 如果想无限循环：不加额外参数就是默认无限循环，如果只播放一次，可以在 `paletteuse` 后面加上 `:loop=0`。
